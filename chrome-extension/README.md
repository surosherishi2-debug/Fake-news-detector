# TruthLens-Omni Chrome Extension (Manifest V3)

Real-time neuro-symbolic factual verification, contextual nutrition cards, and AI hallucination detection directly in Google Chrome, Brave, and Microsoft Edge.

---

## 🚀 1-Minute Installation Instructions

1. **Start the TruthLens-Omni Backend**:
   Ensure the local server is running:
   ```powershell
   python run.py
   ```
   *(Listening on `http://127.0.0.1:8000`)*

2. **Load the Extension in Chrome**:
   - Open Google Chrome and navigate to: `chrome://extensions/`
   - Enable **"Developer mode"** in the top-right corner.
   - Click the **"Load unpacked"** button in the top-left corner.
   - Select the `chrome-extension/` directory from this repository:
     `E:\Software\FakeX\chrome-extension`

3. **Verify Features**:
   - **Click Extension Icon**: Audit current active tab or paste custom text.
   - **Highlight Any Text on Any Webpage**: A floating `🔍 Audit with TruthLens` chip will appear instantly. Click it to view the real-time verdict and truth score!
   - **Right-Click Context Menu**: Select any text, right-click, and choose **"Verify Claim with TruthLens-Omni"**.
